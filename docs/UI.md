# UI: стиль и компоненты

Как должен выглядеть интерфейс Subtitle Voicer. Экраны — в `docs/design/*.html` (открыть `docs/design/index.html` в браузере). Что делает каждый экран — в `docs/TZ.md`, раздел 4.13. Этот файл — **как это выглядит** и как перенести вид в Qt.

> **Для исполнителя.** HTML-макеты — эталон вида, а не код для копирования. Интерфейс собирается на PySide6 виджетами + общая таблица стилей QSS. Если элемент макета нельзя сделать в Qt без больших усилий — упростить до ближайшего стандартного вида и сказать пользователю, не изобретать сложные самописные виджеты.

---

## 1. Характер

Тёмный «игровой лаунчер» в духе Steam: сине-графитовые панели, один яркий голубой акцент, зелёный — только для статуса «работает». Без градиентов на элементах интерфейса, без теней кроме всплывающих окон, без эмодзи. Плотность средняя: всё помещается в окно 1100×720 без прокрутки на основных вкладках.

## 2. Цвета

Все цвета — константы в одном месте (`ui/theme.py`), QSS собирается из них. Никаких цветов «по месту».

| `bg_window` | `#171d25` | фон окна, меню, всплывающие окна |
| `bg_sidebar` | `#121820` | боковая навигация, поля ввода, чипы |

**Метки (чипы)** — фон + текст одного оттенка:

## 3. Шрифты

| Роль | Шрифт | Размер / вес |
|---|---|---|
| Заголовок вкладки | Exo 2 | 26 px, 700 |
| Заголовок профиля, окна | Exo 2 | 16–20 px, 700 |
| Заголовок секции | Exo 2 | 13–14 px, 600, ПРОПИСНЫЕ, разрядка 0.08em |
| Основной текст | Golos Text | 14 px, 400; подписи 13 px; подсказки 12 px |
| Кнопки | Golos Text | 13–14 px, основная — 600 |
| exe, пути, метрики, словарь | JetBrains Mono | 11–13 px |

Все три шрифта — открытая лицензия (SIL OFL), с кириллицей. Файлы `.ttf` кладутся в `src/subvoicer/ui/fonts/` (вместе с файлами лицензий) и загружаются при старте через `QFontDatabase.addApplicationFont`. Если шрифт не загрузился — системный fallback (Segoe UI), приложение не падает.

## 4. Размеры

- Сетка отступов кратна 4: внутри карточек 16–20 px, между карточками 16–18 px, поля окна 28×32 px.
- Скругления: карточки и окна 12 px, кнопки и поля 8 px, мелкие кнопки 6–7 px, чипы — полностью круглые.
- Высота: кнопки 34–40 px, поля 34–38 px, строка таблицы ~48 px, пункт меню ~38 px.
- Боковая навигация 240 px; окно настроек по умолчанию 1100×720 (вкладка «Профили» может прокручиваться).
- Кликабельные элементы не меньше 32×32 px, основные — 38+ px.

## 5. Компоненты

| Компонент | Вид | В Qt |
|---|---|---|
| Окно | Свой заголовок 40 px (логотип + «SUBTITLE VOICER», свернуть, закрыть в трей) | Для MVP — **стандартная рамка Windows** с тёмным заголовком (`DwmSetWindowAttribute`, DWMWA_USE_IMMERSIVE_DARK_MODE). Свой заголовок — только если пользователь попросит |
| Навигация | Вертикальный список, выбранный пункт — фон `bg_active`, иконка акцентом, **без** цветной полосы сбоку | `QListWidget` / кнопки в `QButtonGroup` + `QStackedWidget` |
| Карточка-секция | `bg_card`, рамка `border`, радиус 12 | `QFrame` с objectName и QSS |
| Основная кнопка | `accent`, текст `on_accent`, 600 | `QPushButton#primary` |
| Вторичная | `bg_control`, рамка `border_control` | `QPushButton` по умолчанию |
| Переключатель | 44×24, выкл `border_control`, вкл `accent`, кружок `on_accent` | Небольшой свой виджет `ToggleSwitch(QAbstractButton)` с `paintEvent` — единственный допустимый самописный контрол |
| Сегменты | Группа кнопок в рамке, выбранная — `bg_control` | `QPushButton` checkable в `QButtonGroup` (exclusive) |
| Ползунок | Акцентная заливка, значение справа от подписи акцентом | `QSlider` + QSS (`groove`, `handle`, `sub-page`) |
| Выпадающий список | Тёмное поле, стрелка справа | `QComboBox` + QSS |
| Клавиша | `bg_control`, рамка, нижняя граница 3 px | `QLabel` с QSS |
| Чип-метка | см. таблицу меток | `QLabel` с QSS, радиус = половина высоты |
| Таблица | Шапка `bg_card_header` ПРОПИСНЫМИ 11 px, строки через `divider` | `QTableView` + модель; кнопки в строке — делегат или виджеты в ячейке |
| Иконки | Контурные, 2 px, 16–18 px | Набор SVG в `ui/icons/` (стиль Lucide, лицензия ISC), красятся под цвет текста |
| Меню трея | Обычное `QMenu` + QSS; «Последние реплики» — подменю, в каждой строке имя + начало фразы | `QSystemTrayIcon` + `QMenu` |
| Уведомления | Карточка у трея с 1–2 кнопками | Своё безрамочное окно `Qt.Tool | FramelessWindowHint` в правом нижнем углу основного монитора; стандартные уведомления Windows не поддерживают кнопки из Qt |
| Редактор зон | Кадр на весь монитор игры, затемнение 45%, зоны — рамки 2 px (выбранная сплошная с угловыми маркерами, остальные пунктир), справа панель 400 px | Безрамочное окно поверх всех на мониторе игры, `QGraphicsView` или свой `paintEvent` |
| Оверлей | Полупрозрачная панель в углу + тонкие рамки зон | Окно `WindowTransparentForInput`, `WA_TranslucentBackground`, поверх всех |

## 6. Тексты

- Весь интерфейс на русском. Кнопки — глаголом («Сохранить», «Прослушать»), без точек.
- exe, пути, горячие клавиши в подписях и метрики — моноширинным шрифтом.
- Игра на экранах — Cyberpunk 2077 как пример; имена голосов («Голос 06») условные, реальные берутся из `voices.toml`.

## 7. Доступность

- Контраст текста не ниже 4.5:1 на своём фоне (все токены выше подобраны так).
- Всё управляется с клавиатуры: порядок Tab по смыслу, видимый фокус — рамка `accent` 2 px.
- У кнопок-иконок есть всплывающая подсказка и `accessibleName`.
- Состояние не передаётся только цветом: у чипов всегда есть текст.
