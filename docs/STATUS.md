- **Этап 2 — захват и конвейер текста (закрыт 2026-09-29):**
  - Захват окна WGC с восстановлением по 4.1 и переходом на DXGI при чёрных кадрах (с проверкой экрана); поиск окна по exe, DPI awareness v2.
  - Автомат 4.4 с правилами посимвольной печати (ТЗ 1.12), dedup (шаги 0–6), говорящий `prefix`/`none` (ТЗ 1.11: имя без цифр), источник реплик по зонам, сервисы, команда `cli watch`.
  - Инструменты: `tools/subtitle_player.py` (тестовое окно с субтитрами), `tools/capture_probe.py` (проверка HDR).
  - Критерии: летсплей GTA 5 — реплики по одной без дублей, при неизменном субтитре OCR не вызывается (18 вызовов на 18 текстов); посимвольная печать — одна реплика; повтор через пустую зону — дважды; «Совет: …» — целиком без имени; после сна ПК и смены разрешения захват восстанавливается (проверил пользователь); HDR — у пользователя нет HDR-монитора, записано в `DECISIONS.md`; 181 тест зелёный.
  - Рабочая команда для летсплея GTA 5: `watch --exe firefox.exe --rect 0.2,0.91,0.8,0.99 --preset color --color-hsv 0,0,190:179,60,255 --speaker prefix`.
