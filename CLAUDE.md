# CLAUDE.md

Subtitle Voicer — Windows-приложение, которое читает русские субтитры с экрана игры (захват окна → маска текста → OCR) и озвучивает их локальным TTS (Silero). Полное ТЗ: `docs/TZ.md`. Перед любой задачей сверяйся с ним; если решение расходится с ТЗ — сначала спроси, потом правь ТЗ.

## Как работаем
- Работаем **по этапам** из раздела 10 `docs/TZ.md`. Этап закрыт, только когда выполнены его критерии «Готово, когда». Не забегай вперёд.
- Небольшие коммиты с понятными сообщениями на русском.
- Новые зависимости — только если они есть в стеке ТЗ (раздел 7) или с объяснением, зачем.
- API сторонних библиотек (silero, silero-stress, rapidocr, windows-capture, pycaw) сверяй с их актуальной документацией, не пиши по памяти.

## Команды
- Установка: `uv sync`
- Тесты: `uv run pytest`
- Линт: `uv run ruff check .` и `uv run ruff format .`
- Проверка стека: `uv run python tools/smoke_stack.py`
- Бенчмарк OCR: `uv run python tools/ocr_bench.py`

## Код
- Python 3.12, пакет `src/subvoicer/`, полные type hints.
- Идентификаторы и docstring — на английском; UI, логи для пользователя и сообщения коммитов — на русском.
- Windows-специфичный код (захват, звук, ducking, хоткеи, окна) — только за интерфейсами (`Protocol`) из раздела 5.3 ТЗ. Логика (`vision`, `pipeline`, `text`, `scheduler`, `profiles`) не импортирует Windows-модули и тестируется чистым pytest с фейками.
- Бизнес-логика не зависит от Qt. GUI получает события через сигналы.
- Стадии конвейера — отдельные потоки, связь через `queue.Queue`. Ни один поток не должен ронять приложение: ловить, логировать, продолжать.
- Конфиги и профили — pydantic v2 модели, данные в `%APPDATA%/SubtitleVoicer/` через `platformdirs`.

## Жёсткие правила
- OCR и TTS — на CPU. GPU не трогать без явного флага в настройках.
- OCR запускается только при изменении **маски** текста, не сырых пикселей.
- Громкость игры после ducking **всегда** восстанавливается (выход, исключение, закрытие игры, следующий запуск после падения).
- Никаких инъекций в процессы игр (DLL, хуки) до позднего этапа 10.
- Модели и сгенерированные данные не коммитить (см. `.gitignore`).
- Реальные тестовые кадры: `tests/fixtures/real/<игра>/имя.png` + `имя.txt` с правильным текстом.
