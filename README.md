# Subtitle Voicer

Автоозвучка русских субтитров в играх без русской озвучки. Приложение захватывает окно игры, распознаёт субтитры (OCR) и озвучивает их локальным синтезом речи. У каждого персонажа свой голос, звук игры на время реплики приглушается.

- Только Windows 10/11.
- Всё работает локально, без интернета (кроме первой загрузки моделей): OCR — RapidOCR (PP-OCRv5), синтез — Silero v5 / v5.5, оба на процессоре.
- В игры ничего не внедряется: только захват окна (Windows Graphics Capture, запасной путь — DXGI).

## Возможности

- **Профиль на каждую игру.** Игры Steam, Epic и GOG находятся сами, любую другую можно добавить по exe. Профиль включается, когда игра запущена.
- **Зоны субтитров.**
  - «Субтитры (авто)» сама находит подложки субтитров внизу экрана.
  - Свои зоны рисуются в редакторе поверх игры (игра на это время ставится на паузу) или по скриншоту. Есть шаблоны, пипетка цвета текста и предпросмотр распознавания.
  - Зону можно читать автоматически или по своей горячей клавише (записки, задания).
- **Кто говорит.** Имя ищется перед текстом («Джуди: …»), над ним, в скобках («[ П-3 ]»), в отдельной зоне или по цвету имени. Несколько реплик разных персонажей в одном субтитре разделяются.
- **Голоса.**
  - Голос персонажу назначается автоматически по полу.
  - Голос можно сменить и прослушать.
  - Голоса со «★» — улучшенные голоса Silero v5.5.
  - Отдельно ставятся голоса персонажей поверх Silero (RVC / so-vits-svc, лучше на видеокарте).
- **Речь как в игре.** Новая реплика может ждать, перебивать старую или ускорять её дочитывание; этот режим и скорость речи задаются в общих настройках или отдельно для игры. Есть словарь произношений с ударениями. Числа и латиница читаются по-русски.
- **Приглушение игры** на время реплики (ducking). Громкость возвращается всегда, даже после падения.
- **Фильтры.** Повторы реплик, мусор распознавания, подсказки интерфейса и список «Не озвучивать» у каждой игры.

## Установка

### Установщик

```bash
uv run --group build python tools/build.py
```

Собирает `dist/SubtitleVoicer-Setup-<версия>.exe` (нужен [Inno Setup 6](https://jrsoftware.org/isinfo.php): `winget install --id JRSoftware.InnoSetup -e`). Программа ставится без прав администратора в `%LOCALAPPDATA%\Programs\SubtitleVoicer`.

### Из исходников

Нужны Python 3.12 и [uv](https://docs.astral.sh/uv/).

```bash
uv sync
uv run python -m subvoicer
```

При первом запуске скачиваются модели OCR и синтеза (окно с прогрессом, проверка SHA-256).

## Как пользоваться

1. Запустите игру. Приложение живёт в трее и само замечает игру из списка «Профили и голоса».
2. У нового профиля уже есть зона «Субтитры (авто)». Если субтитры без подложки или имя стоит по-особому, откройте редактор зон (Ctrl+Alt+Z) и настройте зону.
3. Играйте: реплики озвучиваются по мере появления. Последние реплики видны в меню трея, там же можно исправить произношение.

Горячие клавиши по умолчанию (меняются в «Горячих клавишах»):

| Клавиши | Действие |
|---|---|
| Ctrl+Alt+P | Пауза / продолжить автоозвучку |
| Ctrl+Alt+R | Повторить последнюю реплику |
| Ctrl+Alt+S | Пропустить текущую реплику |
| Ctrl+Alt+A | Выделить область и прочитать |
| Ctrl+Alt+Z | Редактор зон поверх игры |
| Ctrl+Alt+D | Кадр для отладки распознавания |

Клавиши регистрируются в Windows и работают и в играх, запущенных от администратора. Сочетание, занятое другой программой, не работает, и приложение об этом сообщает.

Данные (настройки, профили, модели, логи) лежат в `%APPDATA%\SubtitleVoicer`.

## Разработка

```bash
uv sync
uv run pytest                          # тесты
uv run ruff check .                    # линтер
uv run ruff format .                   # форматирование
uv run lint-imports                    # правила зависимостей между слоями
uv run python tools/smoke_stack.py     # проверка стека: OCR + синтез в smoke.wav
uv run python tools/ocr_bench.py       # бенчмарк OCR на синтетике
```

Перед коммитом должны быть зелёными `ruff check`, `ruff format --check`, `lint-imports` и `pytest`. CI нет, проверки только локальные.

Код — `src/subvoicer/`, слоями:

| Пакет | Что внутри |
|---|---|
| `core/` | Модели данных, события, порты (`Protocol`) |
| `config/` | Настройки и профили (pydantic), миграции, хранение |
| `pipeline/` | Чистые алгоритмы: маски, стабилизатор, dedup, говорящий, подготовка текста, планировщик речи |
| `engines/` | Адаптеры к библиотекам и Windows: захват, OCR, TTS, аудио, хоткеи, библиотеки игр |
| `sources/` | Откуда берётся текст: OCR по зонам, ручное чтение |
| `services/` | Потоки и очереди: захват, зоны, озвучка, слежение за игрой |
| `app/` | Сборка и жизненный цикл, фасад для интерфейса |
| `ui/` | Интерфейс на PySide6 |

Тесты — `tests/`: юнит-тесты на фейках (`tests/fakes/`), контрактные тесты движков, интеграционные на реальных кадрах игр (`tests/fixtures/real/`; крупные наборы кадров есть только у автора, без них такие тесты пропускаются).
