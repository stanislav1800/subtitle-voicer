# Subtitle Voicer

Автоозвучка русских субтитров в играх без русской озвучки. Приложение захватывает окно игры, распознаёт субтитры (OCR) и озвучивает их локальным синтезом речи — у каждого персонажа свой голос, звук игры на время реплики приглушается.

- Только Windows 10/11.
- Всё работает локально: OCR (RapidOCR, PP-OCRv5) и TTS (Silero v5) на CPU.
- Профили для каждой игры: зоны субтитров, способ определения говорящего, голоса персонажей, словарь произношений.

Статус: в разработке. Техническое задание — [docs/TZ.md](docs/TZ.md).

## Разработка

```bash
uv sync
uv run pytest
uv run ruff check .
uv run lint-imports
uv run python tools/smoke_stack.py   # проверка стека: OCR + синтез в smoke.wav
```

Первый запуск `smoke_stack.py` скачивает модели OCR и TTS (около 100 МБ).
